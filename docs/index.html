One real turn

Watch the run
from the inside.

The same session as the video, slowed down. One sentence in, a three-worker audit out, and a record of everything that happened in between.

1You ask

Plain language in. The pilot decides how deep to go.

Every turn is sized as MICRO, STANDARD or DEEP before the model acts. This one asked for a swarm, so the pilot hands it to the kernel instead of grinding through one long context window.

2The kernel takes the job

Three roles. Three leases. One durable job.

Puppetmaster splits the audit into an explorer, a conflict auditor and a test coverage reviewer. Each role gets a capability bar, a routed model, and a five-second lease that a heartbeat keeps alive.

3Workers write to state

Findings land in SQLite while the run is still going.

This job wrote 25 artifacts, each with a sha256: 11 findings, 2 risks, 3 decisions, 6 verifications and 3 routing records. All three workers finished in 67 seconds and graded their own coverage PASS, so the tracker marks the job done. A worker that fails or comes back partial is marked that way instead of painted green.

4The answer streams

One answer, and it says what it checked.

The pilot ranked six findings with file and line, re-read the regex behind the top one to confirm it, and closed with what to fix first.

5You get a receipt

Depth, tokens, cache and dollars, in the status bar.

The meter runs live: turn depth, tokens, cache hit rate and actual spend, plus what your plan covered when a plan pays for the tokens. The job receipt prices each worker against the model registry in force when it finished.

Leases, not hope

A worker holds a lease and renews it on every heartbeat. A dead worker forfeits it and the task is recoverable.

Typed artifacts

Findings, risks, decisions and verifications carry confidence, citations and a content hash.

A job graph

Every task links to what it produced. 26 edges in this job, queryable after the fact.

Zero-token recall

Pull a finished job's results into any later session without re-running a single model call.

Cost-aware routing

The cheapest model
that clears the bar.

Every task carries a capability requirement. The router scores every model you allowed, picks the cheapest one that clears it, and writes down why it turned down the rest. These are the real routing records from the run.

routing artifact · reason
51candidates scored on a first route, with a written reason for each one turned down.
Auto-fallbackA rate-limited worker is re-routed to the next model that clears the bar, and the switch is recorded. Explicit pins never get silently swapped.
Cache affinitySibling tasks keep the same model when it still clears the bar, so the shared job brief stays cached.

  1. Send less

    CodeGraph-first retrieval injects the symbols that matter instead of whole files, so prompts start small.

  2. Re-send cheap

    Prompt caching with a stable and a moving breakpoint across Anthropic, OpenAI and Gemini serves the heavy prefix from cache every turn.

  3. Bill honestly

    Cached tokens are priced at the real cache-read discount, and unknown prices stay unknown instead of turning into a quiet $0.

  4. Route down

    The router will pick a competitor's open-weights model when it clears the bar. A first-party tool will never route you off its own tokens.
